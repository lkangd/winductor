# 拓扑身份按邻接关系判定，不含分辨率

拓扑 = 屏幕 UUID 集合 + 邻接排列（每对相邻屏贴合的边、同一边上邻居的先后）+ 各屏旋转方向；分辨率、沿边偏移量、主屏选择都不参与。原因：macOS 以主屏左上角为原点的 point 坐标表达排列，改任一屏分辨率都会让其他屏的坐标漂移，按坐标判定会让「只改分辨率」变成另一个拓扑；而窗口几何按所属屏归一比例存储，分辨率与主屏变化本就能正确恢复。

## Considered Options

- 只看 UUID 集合（旧口径）：拖换左右顺序后仍判同一拓扑，按旧排列恢复会把窗口放到「语义上错误」的屏。
- 屏数 + 排列 + 分辨率、不认 UUID：能匹配陌生的同型号显示器，但同型号双屏无法区分左右，且分辨率进身份与归一几何的设计相悖。

## Consequences

- 在系统设置里把某块屏拖到另一条边，已有预设会落到另一个拓扑下（主窗口仍可见，但不再自动匹配）；只上下/左右微调同一边上的偏移不受影响。
