# 手动预设取代自动快照

Winductor 起初是「后台每 2s 差分、自动落盘现势快照，屏幕集合变大且精确匹配时自动恢复」，并为此维护冻结点账本（`ReturnHomeLedger`）防止拔屏后的少屏布局覆盖拔屏前的快照。现改为：布局只在用户手动「保存为预设」时落盘，一个拓扑可存多个具名预设；拓扑变化后命中自动预设即恢复，否则从菜单栏弹恢复提示由用户确认。原因：固定三屏的假设被放开后，「哪份自动快照代表用户想要的布局」不再可判定——冻结点、home 拓扑、超集放行等规则随屏数组合爆炸，且自动快照会把临时凌乱的布局当成目标。

## Consequences

- 恢复的是上次手动保存的布局，而不是拔屏前那一刻的布局；用户不保存，布局变了也不会被记住。
- 后台轮询、冻结点账本、home/超集判定、`history-*` 滚动历史整体删除；回滚快照（恢复前自动拍、单层撤销）保留——它是安全网，不是记录。
- 应用启动时不恢复（登录时窗口未齐，部分匹配弊大于利）。
